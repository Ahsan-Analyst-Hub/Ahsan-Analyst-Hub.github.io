# Retail Intelligence Studio — website starter

A responsive, light-theme static website concept for a Data Analytics and Business Intelligence consultancy, with Customer Feedback Intelligence as a specialist focus.

## Included
- `index.html` — page structure and content
- `styles.css` — responsive layout and sophisticated light colour theme
- `script.js` — dropdown navigation, mobile navigation, project filters and mailto enquiry form

## Before publishing
1. Open `script.js` and replace `YOUR-EMAIL@example.com` with the email address you want enquiries sent to.
2. Review the business name `RETAIL INTELLIGENCE` / `Retail Intelligence Studio` and replace it with your final brand name if needed.
3. Verify each repository link and project description before making the website public.
4. The contact form opens the visitor's email application. It does not send or store data on a server. To collect submissions directly on the website, connect a form service or backend and publish an appropriate privacy notice.
5. Portfolio case studies using synthetic/sample data are labelled as demonstrations; keep that disclosure.

## Preview locally
Double-click `index.html` to open it in a browser.

## Publish free with GitHub Pages
1. Download and unzip this folder.
2. Open your existing GitHub Pages repository and make a backup of the current files.
3. Upload `index.html`, `styles.css`, `script.js` and any assets into the repository root, replacing the old site only after reviewing the preview.
4. Commit the changes.
5. In the repository, open **Settings → Pages** and confirm the publishing source is the correct branch and root folder.
6. Visit `https://ahsan-analyst-hub.github.io/` after deployment finishes.

You can also deploy these files to Cloudflare Pages by creating a Pages project and uploading the static site files.

## Notes
- Google Fonts is loaded from an external provider; the page falls back to system fonts if it is unavailable.
- All dashboard-like graphics are illustrative design elements, not live business data.
